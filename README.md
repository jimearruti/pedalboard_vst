# Pedalboard VST

<img width="1065" height="706" alt="{0971F71F-3F94-44B4-96DE-0B504745764E}" src="https://github.com/user-attachments/assets/08108c16-67c8-446a-83ab-b15ff264f1e8" />

This project consisted of the implementation of a Pedalboard VST and Standalone plugin using JUCE. The Pedalboard is composed of an octave-down effect, an overdrive effect, 
and a reverb that includes freeze and shimmer options. All effects can be used simultaneously without generating audible artefacts, and each pedal can be bypassed.
